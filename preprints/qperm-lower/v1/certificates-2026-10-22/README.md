# Stronger dimension-eighteen certificate, 22 October 2026

This release is separate from the frozen `certificates/` release. It retains
the old exact seeds in dimensions 4–17 and replaces the dimension-eighteen
seed by

\[
\gamma_{18}=-\frac{34110757033}{10^{12}}=-0.034110757033.
\]

The previous seed was \(-0.0342921802\). The new certificate uses the same
projection-spectral and compatible mixed-coefficient relaxation, with
spectral moments retained through degree ten in the numerical proposal.
Its exact dual vector satisfies every row of the full rational model.
No optimality over either maps or the relaxation is asserted.

Exact shifted-polynomial checks establish

\[
\Phi_n(H)\ge -\frac{n-1-K}{n(n-1)+K}\quad(n\ge18),\qquad
K=\frac{6562108347902}{1034110757033}>\frac{19}{3}.
\]

Combining the transported tail with the existing seeds in dimensions 8–17 gives

\[
\Phi_n(H)\ge-\frac{3n}{3n^2+19n+111}\qquad(n\ge8).
\]

This strictly improves the previous headline bound
\(-5n/(5n^2+31n+190)\) at every integer \(n\ge8\). Their difference is
\(n(2n-15)/[(3n^2+19n+111)(5n^2+31n+190)]\).
The stronger existing finite bounds remain available; this single formula
is not claimed to dominate every previously recorded bound.

A stronger smooth envelope is

\[
\Phi_n(H)\ge-\frac{n}{n^2+Kn+B_*}\quad(n\ge8),\qquad
B_*=\frac{201367792086857761456}{5453923917139453759}.
\]

Here \(B_*=800000000/5274023-64-8K\), so the bound equals the
dimension-eight seed at \(n=8\). The exact finite comparisons hold in
dimensions 8–17, and the tail numerator is
\((K^2+2K-B_*)n+B_*(K+1)\), with both coefficients positive.
Compared with the previous smooth envelope, the denominator increases by
\((K-K_{18,\mathrm{old}})(n-8)\). The new bound is therefore equal at
dimension eight and strictly stronger in every larger dimension.

## Exact verification

Run from the repository root:

```sh
python3 certificates-2026-10-22/verify.py
```

Only Python's standard library is required. The verifier checks the entire
dependency chain from the nonpositive seeds in dimensions two and three,
all rational dual inequalities, the stored primal vectors in dimensions
4–7, all 82 shifted transport polynomials, the finite comparisons, the
clean and smooth envelope identities, and release checksums. It writes the deterministic
`verification.json` and normally takes about 25–35 seconds on the host used
for this computation.

`SHA256SUMS` covers all release inputs. The generated `verification.json`
is deliberately excluded so it can be regenerated by the verifier.

`PROVENANCE.json` identifies the source of each copied file. The six model
builders are unchanged copies of the frozen release, and no file in the
frozen release was modified. The mathematical validity of those model rows
uses the manuscript's mixed determinant and projection-spectral arguments;
the computation checks the exact finite certificates, not those analytic
proofs independently.

## Numerical discovery

The proposal was generated with NumPy/SciPy and accepted only after exact
dual repair and full rational verification. The scratch command was:

```sh
python3 restructure-work/bounds-compute/extend_certificates.py --start 18 --end 18 --degree 10
```

The solver reported an objective approximately \(-0.03411071471138538\).
The certified bound above is the downward-rounded repaired dual objective.
A degree-twelve attempt failed with a HiGHS solve error and supplied no
accepted certificate. The degree-ten result does not depend on that attempt.
A dimension-nineteen numerical exploration did not produce an accepted
certificate and is not part of this release.
